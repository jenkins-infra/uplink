= Uplink

image:https://img.shields.io/docker/pulls/jenkinsciinfra/uplink.svg[link="https://hub.docker.com/r/jenkinsciinfra/uplink/"]

`uplink` is a simple web application to receive short bursts of anonymous telemetry data from Jenkins instances.

image::https://raw.githubusercontent.com/rtyler/uplink/master/public/logged-in.png[role=center, title="Logged in to Uplink"]

== Development

=== Requirements

* GNU Make
* Docker CE and (Docker) `compose` plugin
* (Optional) You can pass custom secrets as environment variables in (git-ignored) `.secrets.env` in `KEY=VALUE` format:
** Use your own GitHub Oauth application by specifying the client ID with `CLIENT_ID` and client secret with `CLIENT_ID`
** Enable Sentry by specifying your custom DSN with `SENTRY_DSN`

=== Tasks

* `make` command defaults to the autogenerated `help` goal. Use it!
* Running tests: `make check`
* Running the server in local development mode: `make run` (With empty database)
* Running the server in "production-like" mode: `make run-prod` (starts by inserting data from the `./seeders` data set)
* Upload a test event: `make generate-event`
* Database Debugging: `make debug-db``
* Spin up an interactive shell inside the NodeJS development environment: `make run shell`
